Pause stops everything, including reject votes. A reject is still a signature, so a paused signer that kept submitting rejections would not be paused. While paused, transactions simply stay pending — nothing is lost, and the backlog is handled when you resume.

Key page governance

Compromise mode is not the default, and the difference matters. A routine rotation swaps the key but leaves the page version alone, so anything the old key already signed at the current version stays valid. Compromise mode bumps the version, resetting the nonces and invalidating those signatures. If a key may be in someone else's hands, use it.
Key-page operations are disabled: this console was started without GOVERNANCE_KEY. Changing a key changes who can act for you, so it is a separate credential from the pause.
